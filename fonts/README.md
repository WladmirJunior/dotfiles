# Terminal fonts

Fonts selected for the vintage CRT / terminal aesthetic used by the Blink Shell themes in this repository.

- `terminus/TerminusTTF-4.49.3.ttf` — Terminus
- `3270/3270-Regular.ttf` — IBM 3270
- `departure-mono/DepartureMono-1.500.otf` — Departure Mono
- `berkeley-mono/` — metadata only; Berkeley Mono is proprietary and is not redistributed here

Each vendored open font includes its upstream license file.
